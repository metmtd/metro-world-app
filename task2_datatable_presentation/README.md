# 📊 Возможности пакета data.table в R

Интерактивная веб-презентация, демонстрирующая основные возможности пакета `data.table` для работы с данными в R.

## Описание

Презентация создана для изучения и демонстрации мощных возможностей пакета `data.table` - высокопроизводительного инструмента для манипуляций с данными в R. Используются данные о Wi-Fi зонах и видеокамерах Санкт-Петербурга.

## Разделы презентации

1. **Введение** - основные концепции data.table
2. **Синтаксис data.table** - структура DT[i, j, by]
3. **Фильтрация данных** - интерактивные примеры фильтрации
4. **Индексация** - демонстрация производительности
5. **SQL-подобные запросы** - группировка и агрегация
6. **IF-THEN-ELSE операции** - условная логика
7. **Объединение данных** - joins и merge операции
8. **Производительность** - сравнение с другими пакетами
9. **Заключение** - резюме и полезные ресурсы

## Особенности

- 🎯 **Интерактивность** - живые примеры с фильтрами
- 📊 **Визуализация** - графики и диаграммы с Plotly
- 💻 **Код примеры** - эквивалентный код на R и Python
- 📱 **Адаптивность** - работает на всех устройствах
- 🔍 **Навигация** - удобное меню в боковой панели

## Технологии

- **Streamlit** - веб-фреймворк для презентации
- **Pandas** - аналог data.table в Python
- **Plotly** - интерактивные графики
- **NumPy** - численные вычисления

## Данные

Презентация использует симулированные данные:
- **Wi-Fi зоны** - 500 записей о публичных точках доступа
- **Видеокамеры** - 300 записей о системе видеонаблюдения
- **Районы СПб** - информация о 8 районах города

## Запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск презентации
streamlit run main.py
```

Презентация будет доступна по адресу: http://localhost:8501

## Файлы проекта

- `main.py` - основное Streamlit приложение
- `data_table_presentation.Rmd` - R Markdown версия презентации
- `README.md` - документация проекта
- `requirements.txt` - зависимости Python

Демонстрация основных возможностей пакета `data.table`:

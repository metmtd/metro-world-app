# 🎓 Проекты TOI (Теория обработки информации)

Репозиторий содержит два веб-приложения, созданных в рамках изучения современных технологий обработки и визуализации данных.

## 📁 Структура проекта

```
TOI/
├── task1_metro_app/           # Задание 1: Метрополитены мира
│   ├── main.py               # Streamlit приложение
│   ├── requirements.txt      # Зависимости
│   └── README.md            # Документация
├── task2_datatable_presentation/  # Задание 2: Презентация data.table
│   ├── main.py               # Streamlit презентация
│   ├── data_table_presentation.Rmd  # R Markdown версия
│   ├── requirements.txt      # Зависимости
│   └── README.md            # Документация
└── README.md                # Общая документация
```

## 🚇 Задание 1: Метрополитены мира

Интерактивное веб-приложение для изучения систем метрополитена по всему миру.

**Технологии:** Streamlit, Folium, Pandas, Plotly

**Функции:**
- Статистика по странам
- Интерактивные карты
- Графики и диаграммы
- Фильтрация данных

[Подробнее →](task1_metro_app/README.md)

## 📊 Задание 2: Возможности data.table

Веб-презентация, демонстрирующая основные возможности пакета `data.table` для работы с данными в R.

**Технологии:** Streamlit, Pandas, Plotly, R Markdown

**Разделы:**
- Синтаксис data.table
- Фильтрация и индексация
- SQL-подобные запросы
- IF-THEN-ELSE операции
- Производительность

[Подробнее →](task2_datatable_presentation/README.md)

## 🛠️ Технологический стек

- **Python 3.8+** - основной язык программирования
- **Streamlit** - фреймворк для создания веб-приложений
- **Pandas** - обработка и анализ данных
- **Plotly** - интерактивная визуализация
- **Folium** - интерактивные карты
- **NumPy** - численные вычисления

## 📋 Требования

- Python 3.8 или выше
- pip для установки зависимостей
- Современный веб-браузер

## 🎯 Цели проекта

1. **Изучение веб-технологий** - создание интерактивных приложений
2. **Визуализация данных** - работа с картами и графиками
3. **Анализ данных** - демонстрация возможностей data.table
4. **Современные инструменты** - использование Streamlit и Plotly

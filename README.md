# Веб-приложение "Метрополитены мира"

Интерактивное веб-приложение для изучения информации о метрополитенах разных стран мира.

## Функциональность

- **Выбор страны**: Боковая панель с выпадающим списком стран
- **Отображение карты**: Показывает город с наибольшей протяженностью метро в выбранной стране
- **Информация о метро**: Дата открытия, количество линий и станций
- **Список городов**: Кнопка "Город" показывает все города страны с метро, отсортированные по протяженности

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
streamlit run main.py
```

3. Откройте браузер по адресу: http://localhost:8501

## Структура данных

Приложение содержит данные о метрополитенах следующих стран:
- Россия (Москва, Санкт-Петербург)
- США (Нью-Йорк, Вашингтон, Сан-Франциско)
- Китай (Шанхай, Пекин, Гуанчжоу)
- Великобритания (Лондон, Глазго)
- Франция (Париж, Лион)
- Япония (Токио, Осака)

## Технологии

- **Streamlit**: Веб-фреймворк для создания интерфейса
- **Folium**: Библиотека для создания интерактивных карт
- **Pandas**: Обработка и отображение данных в табличном виде

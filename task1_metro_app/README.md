# 🚇 Метрополитены мира

Интерактивное веб-приложение для изучения систем метрополитена по всему миру.

## Описание

Приложение предоставляет информацию о метрополитенах различных стран с интерактивными картами, статистикой и визуализацией данных.

## Функциональность

- 📊 **Статистика по странам** - количество станций, протяженность линий
- 🗺️ **Интерактивные карты** - визуализация расположения метрополитенов
- 📈 **Графики и диаграммы** - анализ данных по регионам
- 🔍 **Фильтрация и поиск** - поиск по странам и городам
- 📱 **Адаптивный интерфейс** - работает на всех устройствах

## Технологии

- **Streamlit** - веб-фреймворк для создания интерфейса
- **Folium** - интерактивные карты
- **Pandas** - обработка данных
- **Plotly** - интерактивные графики

## Запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
streamlit run main.py
```

Приложение будет доступно по адресу: http://localhost:8501

## Структура данных

Приложение использует данные о метрополитенах включающие:
- Название страны и города
- Количество станций
- Протяженность линий
- Год открытия
- Координаты для карты
